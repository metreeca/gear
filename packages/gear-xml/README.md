# @metreeca/gear-xml

[![npm](https://img.shields.io/npm/v/@metreeca/gear-xml)](https://www.npmjs.com/package/@metreeca/gear-xml)

XML and HTML processing tasks for [@metreeca/gear](https://github.com/metreeca/gear).

# Installation

```shell
npm install @metreeca/gear      # the job execution API
npm install @metreeca/gear-xml  # this package
```

> [!IMPORTANT]
>
> Node.js 22 or later is required.

> [!WARNING]
>
> TypeScript consumers must use `"moduleResolution": "nodenext"/"node16"/"bundler"` in `tsconfig.json`.
> The legacy `"node"` resolver is not supported.
