# @metreeca/flow-url

[![npm](https://img.shields.io/npm/v/@metreeca/flow-url)](https://www.npmjs.com/package/@metreeca/flow-url)

URL processing tasks for [@metreeca/flow](https://github.com/metreeca/flow).

# Installation

```shell
npm install @metreeca/flow      # the job execution API
npm install @metreeca/flow-url  # this package
```

> [!IMPORTANT]
>
> Node.js 22 or later is required.

> [!WARNING]
>
> TypeScript consumers must use `"moduleResolution": "nodenext"/"node16"/"bundler"` in `tsconfig.json`.
> The legacy `"node"` resolver is not supported.

# Usage

| Symbol             | Description      |
|--------------------|------------------|
| [`fetch()`][fetch] | Resource fetcher |
